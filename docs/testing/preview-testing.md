# Preview testing

ThisIsMyPC is still in development. There is no published installer yet.
The [README setup](../../README.md#quick-start) explains how to build a preview.
These checks need no coding knowledge once the app is open.

## Explore the preview

1. Open Home.
2. Open each group in the sidebar.
3. Select a page that interests you.
4. Check whether the page explains unavailable controls.
5. Search for a setting you saw on that page.
6. Select the search result.
7. Check whether the app opens the correct setting.

## Try staging and discard

1. Open Explorer.
2. Find Taskbar alignment.
3. Choose the other value.
4. Click 1 change pending at the bottom.
5. Check the previous value and proposed value.
6. Click Discard All.
7. Check that the pending list is empty.

Staging does not apply the setting. Discard All removes the proposed change.

## Try Presets

1. Open Presets.
2. Click Packs.
3. Select Windows 10-ify.
4. Read the individual choices.
5. Clear a choice you do not want.
6. Check whether unavailable choices explain the reason.

On a desktop PC, also open Intro guide from Home.
Check whether the lessons explain each choice before asking you to make it.

## Check readability

1. Make the window smaller.
2. Check whether text stays readable.
3. Scroll a long page.
4. Check whether the scrollbar covers a control.
5. Open Settings.
6. Open Application.
7. Set Theme to Dark or Light.
8. Check the same page again.

## Report what happened

Open a [bug report](https://github.com/No-More-Secrets/thisismypc/issues/new?template=bug-report.md).
Include the page, the clicks, the expected result, and the actual result.
Add a screenshot if the problem is visual.
Copy error text when the app shows an error.
Include the app version or source commit, plus your Windows edition.
Remove personal information before posting.

These checks do not verify live Apply, undo, installation, updates, or hardware changes.
Those checks remain separate acceptance work in the [backlog](../planning/refinement-backlog.md).
