Welcome
============================================================

Windows hides things from you, puts promotions everywhere, lets installed apps fight over your PC, and does many things without giving you a choice. ThisIsMyPC exists to give you those choices back.

Here, every control has been brought into one place. This tutorial will help you understand what Windows is doing to your personal computer, and what you can do about it with the help of this software (and others like it).

Try out settings as you go through the tutorial. Examples are provided of what they will change. At the end, a preset called the Desktop Grand Pack has bundled many cleanup settings for your PC. You will be able to customize it thoroughly before applying, and the vast majority of changes are entirely reversible if you wish to go back.

Software
============================================================

Not everything installed on your PC is there because you wanted it. Windows includes apps of its own, and your PC manufacturer may have added more. An app you never open can still add background services, startup entries, and scheduled tasks. You also may have installed apps over time that you do not want or need anymore.

An Installed App has files saved on your PC. A Process is a running instance of a program, using memory and potentially processor time. Having an app installed does not mean its main program must run all day. Removing its files and stopping its background activity solve different problems.

Apps can register instructions that launch programs without you opening them. These are often broadly referred to as Autoruns. They can launch programs when Windows boots, when you sign in, or when a scheduled time or another event occurs. Boot means Windows starting; sign-in means entering your account. One app can register several Autoruns.

You do not have to uninstall an app to stop this unwanted background activity. You can often disable its Autoruns and keep the app available to open yourself. That is why Software and Startup & Services belong together.

For example, you might use a game launcher on weekends, but it runs in the background all week. If you disable its sign-in entry, that entry no longer opens the launcher every time you enter Windows. You can still open the launcher to play. A separate updater or service might continue running, so the next lesson checks those entries too.

Start with an app you recognize. Decide whether you want to keep using it. If you do, follow it into Startup & Services to examine its automatic launches. If you no longer want it, uninstalling removes the app instead. Keeping an app enabled can also be useful: a messaging app may need to run in the background to notify you.

The Software page has three tabs. App Catalog contains supported programs you can install or uninstall through this app. Select Installed to see catalog entries found on your PC. This is not a complete list of every installed program. If an app is missing, look in Windows Settings under Apps > Installed apps.

Windows Apps contains the supported Windows app packages, including bundled apps such as Clipchamp, News, and Weather. A Package is the unit Windows uses to install and maintain an app. Read an app's description before deciding whether to remove it. If you use Clipchamp to edit videos, keep it. If you never use it, removing it frees its installed storage.

Choose Remove to add a Windows app to the pending list. Pending means the action is selected but has not run yet. These removals affect every account on the PC and stop the package being added automatically to new accounts. Save anything you need from the app before applying the removal. History cannot undo an uninstall. Apps with a Store listing have a reinstall option here, but reinstalling does not guarantee recovery of their previous data.

Updates lists available updates reported by Windows Package Manager, also called winget. This is Microsoft's tool for finding and managing software packages. It does not manage every app on your PC. If you disable an app's own updater later, you still need a way to keep that app updated.

At the end of the tutorial, the Desktop Grand Pack combines many cleanup choices into one preset. A Preset is a saved collection of changes you can review together. Its app removals include Clipchamp, News, Weather, Copilot, and Microsoft 365 Hub when installed. Clear any app you want to keep before applying the pack.

Continue to Startup & Services with an app you want to keep. The next lesson explains how to identify its Autoruns and decide which ones you need.

Startup & Services
============================================================

Installing software often gives it ways to run without you opening it. These automatic-launch entries are broadly called Autoruns. An Autorun is an instruction, not proof that its program is running now. Entries accumulate as you install software, and one app can leave several different instructions for Windows to follow.

Task Manager shows two different parts of this picture. Its Processes page lists running programs and their current resource use. Its Startup apps page lists familiar entries you can enable or disable for sign-in. Disabling a Startup App leaves the app installed and blocks that launch entry. It does not disable every other way the app can start.

The System Tray is the area beside the clock where some programs display icons. The overflow menu holds additional icons. Many background programs have no tray icon at all. Hiding an icon only changes its visibility; it does not stop the program. Choosing Exit from an app's tray menu may stop it now, but its Autoruns can bring it back later.

A Scheduled Task tells Windows to perform an Action when a Trigger occurs. The Action might open an updater. The Trigger might be boot, sign-in, a daily time, an idle PC, or a particular event. Task Scheduler is the Windows tool that manages these tasks. They are separate from Task Manager's Startup apps list. A task can run briefly and finish, so you may never see it in the tray.

A Service is a background program managed by Windows. It can run without a window or tray icon, and some services start before anyone signs in. Services support things such as printing, hardware controls, and software updates. A service's Startup Type controls how it can start. Automatic allows Windows to start it automatically. Manual allows it to start when requested; it does not mean only you can start it. Disabled prevents Windows from starting that service.

Windows also reads automatic-launch instructions from Startup folders and the Registry. A Startup folder contains shortcuts that run at sign-in. The Registry is Windows' settings database; some entries there tell Windows which programs to launch. Drivers support hardware or system functions, while Extensions add behavior inside another program, such as File Explorer. Those can load without creating their own window. These mechanisms are less visible than Startup apps, but they are not all unnecessary background work.

Startup & Services groups the entries it finds by type. Search for the app you chose in Software. The search covers the categories currently included by the page's filters. Windows and other Microsoft entries are hidden by default, so an empty result does not prove an app has no Autoruns.

Start with an entry you recognize. The Publisher identifies who supplied the program. Its file path shows which program Windows will run. Its category tells you which launch mechanism it uses. For a Scheduled Task, the Trigger explains when it runs. Use those details together: a familiar name alone does not explain what an entry does.

Consider the game launcher from Software. A sign-in entry may open its main window or leave it waiting in the tray. If you only play on weekends, you can disable that entry and open the launcher yourself when needed. A separate update task may still check for updates. Decide whether you want that task to continue, rather than assuming the sign-in change controls it too.

Disabling an entry stages a change for review. Applying it changes future launches through that entry; it does not necessarily stop a program already running. After your next sign-in, check whether the unwanted launch stopped. Then open the app yourself and check the features you use. If you need the entry again, restore it. If you no longer want the app, return to Software to uninstall it.

Do not judge cleanup by the number of entries disabled. An unused launcher and a service needed by your mouse can both appear here. Read what the entry supports. If you disable an updater, arrange to check for updates yourself. If an entry's purpose is unclear, leave it enabled while you investigate.

The Desktop Grand Pack includes a preset called Clean Boot. Here, that name means a specific collection of service and task changes. It includes Windows diagnostic-data collection and selected background jobs. Diagnostic data records how Windows and apps behave, including errors. Review the individual entries to see which functions will stop. For example, the pack disables Edge's updater services. Restore both before updating Edge. The preset name does not mean every listed function is useless on your PC.

Windows Search is a separate, optional choice in the pack. Its Indexing Service builds a catalog of file names, file details, and supported contents. Like the index in a book, that catalog helps searches find information without reading every file each time. Maintaining it uses storage and background work as files change.

Disabling Windows Search indexing reduces that work, but searches that depend on the index can become slower or lose results. Outlook configurations that use the Windows index can also be affected. Keep indexing if you rely on those searches. If you rarely use them, you can choose to disable it. You can also reduce the indexed locations in Windows instead of disabling the service.

The pack leaves Windows Search unchecked. Selecting it changes the service's Startup Type to Disabled. It does not delete the existing index or immediately stop a running service. Its effect on indexing begins when the service stops or Windows restarts.

Windows Annoyances
============================================================

A suggestion to try another Microsoft product is an advertisement, even when it appears in Settings. Windows puts promotions in several places, each with its own switch.

Open this module and search for suggestions. Read the matching setting, change it, and check the pending change before applying.

If another promotion appears later, note where it appeared. Start, Settings, and the lock screen have separate controls.

Privacy & Telemetry
============================================================

Windows separates required diagnostic data from optional data. This module also controls activity tracking and advertising personalization.

Open this module and find Diagnostic data. Compare the current value with the available choices; some depend on your Windows edition.

The pack limits optional collection. Check privacy settings inside newly installed apps too, because Windows cannot control every app's own collection.

Explorer
============================================================

File extensions distinguish files such as photo.jpg and photo.exe. Show extensions if you want to see the file type in its name.

Open this module and find the file-extension setting. Enable it, apply the change, then open a folder to compare the names.

The pack hides Widgets and restores the full right-click menu. Some changes may require an Explorer restart.

Context Menus
============================================================

Apps add shortcuts to the menu you see when you right-click a file. Disabling an unused shortcut removes it from the menu without uninstalling the app.

Open this module and find an entry from an app you recognize. Disable it, apply the change, then right-click the same file again to check the result. Keep shortcuts you use often.

Windows Update
============================================================

The pack selects Notify before download, keeps Windows on its current feature release, excludes drivers, and limits automatic restarts.

Open this module to review those choices. If you keep the release pin, remove it before that release stops receiving security fixes. Check for updates regularly when downloads wait for you.

Set active hours around when you use the PC to reduce restart interruptions.

Security
============================================================

Use this module to check antivirus, sign-in, and app protection settings. An antivirus scan can use CPU and disk while doing necessary work.

Turning off a warning does not fix what caused it. Check the named protection before dismissing the warning.

Network & Firewall
============================================================

Connections lists your network adapters. DNS controls which service looks up website addresses. Firewall shows the profiles and rules controlling network access.

VPN software can add adapters and change DNS. An unfamiliar adapter may belong to your VPN, so identify it before disabling it.

Environment
============================================================

PATH is a list of folders Windows searches when you run a command. An installer can add its folder; an uninstaller can leave that entry behind.

Use this module to inspect variables and correct known problems, such as a command opening the wrong version. Leave unfamiliar entries alone.

Power Plans
============================================================

Choose when the screen turns off and when the PC sleeps. Power plans also affect processor behavior, heat, and energy use.

Compare performance during your usual workload before keeping a plan change. If the active plan changes unexpectedly, check your hardware utilities too.

Display
============================================================

Adjust brightness or switch inputs on supported monitors without reaching for their buttons. You can link brightness across displays.

Available controls depend on the monitor. If a control is unavailable here, use the monitor's own menu.

System Control
============================================================

Manufacturer software may combine promotions with useful hardware controls. Check which functions you need before uninstalling it.

System Control provides supported manufacturer controls and companion options. Many target laptops, so this module may have little to offer on a desktop.

Lighting
============================================================

Choose colors and effects for supported lighting devices here. Running two lighting controllers for the same device can make their settings conflict.

If a color keeps changing back, check whether another lighting app starts with Windows.

Cooling
============================================================

Cooling uses supported fan controls and FanControl integration. A fan curve sets fan speed in response to a temperature sensor.

Identify each fan and sensor before changing a curve. Check temperatures under load afterward. A curve copied from another PC may not suit your cooling.

============================================================
Monitoring
============================================================

Compare load, temperatures, and fan speeds while doing the same task before and after a change. A reading taken at idle cannot show whether a game runs better.

A missing sensor means no reading is available. It does not mean the temperature or fan speed is zero.

After cleanup
============================================================

After installing an app, check Startup & Services and Context Menus for entries you did not ask for. After a major Windows update, check your promotion and privacy settings.

History can undo supported setting changes. Owner Mode can restore selected settings when they change; check its supported choices in Settings before enabling it.
